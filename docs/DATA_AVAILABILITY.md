# Data availability

## Manuscript statement

The phenotype data, MAF-filtered genotype matrix, GWAS summary statistics, associative transcriptomics results used to generate the figures, and all R scripts are available in the GWAS_BreadWheat repository at https://github.com/YixiangShan/GWAS_BreadWheat. The RNA-sequencing reads from which the SNP and expression datasets were derived are available under NCBI BioProject PRJNA912645. The repository also provides a complete marker-level MAF summary for the 179,253 input SNPs and the 32,221-SNP matrix used for all MAF-filtered analyses.

## Placement

For G3: Genes|Genomes|Genetics, place the section headed **Data availability** near the end of the manuscript, before the Acknowledgements and References, following the journal's current author instructions.

## Archiving note

The GitHub repository provides open access and version control. Before final publication, archive the accepted repository release in Zenodo and add its DOI to this statement. A DOI identifies the exact version used for the paper and is more stable than a branch URL.
