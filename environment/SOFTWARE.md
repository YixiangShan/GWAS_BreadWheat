# Software environment

The manuscript analyses used R 4.4.0, GAPIT, ADMIXTURE v1.3.0, and PLINK. Three principal components and the GAPIT kinship matrix were used in the GWAS mixed linear model.

The plotting scripts use the R packages listed in `R_packages.tsv`. `sessionInfo.txt` records the local environment used for repository validation on 2026-10-09.

The repository includes the GAPIT function file used during the project in `scripts/vendor/gapit_functions.txt` so the analysis does not depend on a changing remote file.
